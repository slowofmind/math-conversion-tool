\section*{Differential Equations Definitions} 
A \textbf{differential equation} is an equation that contains a derivative (or derivatives).

A \textbf{solution} to a differential equation is a function that satisfies the differential equation.

A graph of a solution is called a \textbf{solution curve}.

The \textbf{order} of a differential equation is the order of the highest order derivative in the equation.

A \textbf{general solution} is the family of all solutions to the differential equation.

An \textbf{initial condition} specifies a value of the dependent value for a specific independent value (i.e. $f(0)=3$). An initial condition specifies a particular solution.

A \textbf{particular solution} is a single function satisfying the differential equation and any initial condition(s).

A \textbf{slope field} is a diagram where at any point $P$ there is a short line segment indicating the slope of the solution curve at that point.

An \textbf{autonomous differential equation} is a differential equation of the form $\frac{dy}{dt}=f(y)$.

An \textbf{equilibrium solution} to a differential equation is a solution that is constant for all values of the independent variable (often $t=$ time). They are sometimes called constant solutions.

A \textbf{stable equilibrium solution} is an equilibrium solution where under slight perturbation the system will tend back toward the equilibrium.

An \textbf{unstable equilibrium solution} is an equilibrium solution where under slight perturbation the system will not tend back toward the equilibrium.

A population model of the form $\frac{dP}{dt}=kP(L-P)$ is a \textbf{logistic growth model} where $L$ is the carrying capacity.

A \textbf{separable differential equation} is a differential equation that can be written in the form $\frac{dy}{dt}=g(t)f(y)$.

When graphing solutions to systems of differential equations, the $xy$-plane is often called the \textbf{phase plane}.

In the phase plane, representative solution curves are called \textbf{trajectories}.

A \textbf{nullcline} is a curve along which $\frac{dx}{dt}=0$ or $\frac{dy}{dt}=0$.

A \textbf{phase portrait} is a graphical representation of trajectories in the phase plane.
