# mathcat-wasm — MathCAT speech proofing engine

Shows, in the platform preview, the text NVDA 2026.2's speech viewer would show
for each equation (MathCAT 0.7.2, NVDA default settings, default OneCore voice).
Design and every decision: `PLAN-MATHCAT-SPEECH-PROOFING.md`.

## Files

| File | Role |
|---|---|
| `mathcat.js` | The engine: `createMathCATEngine({ bytes } \| { url })` → `{ version, nvda, speak(mathml) }` |
| `mathcat_wasm.js` | Generated wasm-bindgen loader (do not edit) |
| `mathcat-wasm.bin` | Gzipped MathCAT wasm (MathCAT's rules are embedded) |
| `BUILD-INFO.json` | Provenance and gate results for the current `.bin` |
| `VERSIONS.md` | Version log and the update procedure |
| `build/` | Wrapper crate (`src/lib.rs`) and `build-container.sh` |
| `test/` | Tests T1–T4, E2E, golden generators, demo generator |
| `../js/mathcat-proof.js` | Platform side: `initMathCATProof(ctx)` |
| `../js/mathcat-proof-agent.js` | In-preview agent (inlined into the preview `srcdoc`) |

## Tests

```bash
cd mathcat-wasm/test
npm install        # jsdom, mathjax 4.1.3, @mathjax/src 4.1.3 (dev only)
npm test           # T1, T1b, T2, T3, T4, E2E
```

- **Goldens** (`golden.json`, `ssml-cases-golden.json`) come from NVDA's own
  `convertSSMLTextForNVDA`. `nvda_reference.py` downloads it from NVDA's
  repository and runs it unmodified. NVDA is GPL-2.0, so its code is fetched
  at generation time and never stored here.
- **Fixtures** (`fixtures.json`): the intent fixtures were produced by the
  platform's own `mathjax-bundle-intent.js` (`make-fixtures.mjs`).

## Demo page (plan Phase C)

`node test/make-demo.mjs` writes `../mathcat-proof-demo.html`: a single file
built from the real modules above.

- **Opened locally:** it shows the popups in a MathJax preview and in a
  plain-MathML preview, both sandboxed exactly like the platform's.
- **Opened from the hosted site (repo root):** its T7 button also tests
  fetching `mathcat-wasm/mathcat-wasm.bin` from inside a sandboxed frame.
