Send your Overleaf project to the ATC tool with one click

This page installs a small browser bookmark (a "bookmarklet"). Once it is on your bookmarks bar, opening any Overleaf project and clicking the bookmark transfers the whole project — every file, including images — directly into the Accessible STEM tool in a new tab. Nothing is uploaded anywhere except from your browser to your browser: the project travels between the two tabs on your own computer.

Before you start: make sure your bookmarks bar is visible. Press Ctrl+Shift+B (Windows) or Cmd+Shift+B (Mac) to show it.

Option 1 — drag to install (most people)

Drag this button up onto your bookmarks bar:

Send to ATC Tool ← drag me to the bookmarks bar (don't click)

Option 2 — copy the code (keyboard & screen reader users)

  1. Press the button below to copy the bookmarklet code.
  2. Open your browser's bookmark manager (Ctrl+Shift+O in Chrome/Edge).
  3. Add a new bookmark: name it Send to ATC Tool and paste the copied code into the URL field.
  4. If your browser removed the leading javascript: from the paste, type it back in at the start.


The code is generated for this copy of the tool (), so always install from the site you intend to use.

Option 3 — import a bookmarks file

Download a small bookmarks file and import it: in Chrome or Edge open the bookmark manager, choose the ⋮ menu → Import bookmarks, and select the downloaded file. The bookmark arrives inside an "Imported" folder — drag it from there onto your bookmarks bar.

How to use it

  1. Open your project in Overleaf.
  2. Click Send to ATC Tool on your bookmarks bar.
  3. A new tab opens with the tool; its status bar narrates the transfer. Large projects can take 15–30 seconds to fetch — that's normal.
  4. When the import finishes, your main document is in the editor and every other project file is listed under the Media tab.
If you see a Harvard login instead of the tool: sign in, then go back to your Overleaf tab and click the bookmark again. The first attempt times out quietly; the second works.

Bookmarklets are desktop-only; phone and tablet browsers don't have a bookmarks bar in the same sense.
