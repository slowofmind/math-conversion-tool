Fix SCORM frames

A bookmark for Canvas Pages that show an imported SCORM package. It sets the frame to fill the column, to be tall enough for the document, and to have a title for screen readers. It shows you the changes first and saves only when you choose Save.

Bookmarks bar
Fix SCORM frames Drag this to your bookmarks bar.

1. Install the bookmark

Show your bookmarks bar with Ctrl+Shift+B, then drag the crimson button above onto it.

If you would rather not drag, copy the bookmark code below and create the bookmark by hand. In Chrome, press Ctrl+Shift+O, open the menu at the top right and choose Add new bookmark. In Edge, go to edge://favorites and choose Add favorite. Name it Fix SCORM frames and paste the code as the URL.

2. Use it

  1. Import the SCORM package as a Page, as usual.
  2. Open that page. It needs to be the page itself, not the editor.
  3. Click Fix SCORM frames in your bookmarks bar. For a moment the frame changes width while the bookmark measures the document.
  4. Check the dialog. It shows the width it will set, a height, and a title. You can change the height and the title.
  5. Choose Save changes. The page saves and reloads.

What it changes

Only the frames that show SCORM packages, and only three settings on each: width (to fill the column), height, and title. It also removes the frame's border. Everything else on the page is left exactly as it was, including any other frames such as videos. Nothing is saved until you choose Save.

It saves through Canvas with your own login, so it can only change pages you could edit yourself. Before saving it reads the page again, and if anyone changed the page since the dialog opened, it stops without saving.

Where the height comes from

Packages made with the new SCORM output report their own height. The bookmark measures them with the frame set to 800 pixels wide, a typical laptop column, so the frame fits there and on anything wider. On a wide screen that leaves some blank space below the document, which on a white page is barely noticeable.

A multi-page package (pages with Next and Previous links) shows every page in the same frame, so it reports the height of its tallest page, measured when the platform made the package. Every page then fits, and shorter pages have some blank space below.

The bookmark also measures the space Canvas's SCORM player takes around the document, and adds it to the height.

Older packages cannot report their height. For those the dialog suggests a number for you to adjust. Scrolling inside the frame first shows how long the document is.

Undoing a change

Canvas keeps every saved version of a page. On the page, open the options menu (the three dots), choose View Page History, select the earlier version and restore it.

This works on Canvas Pages. SCORM packages imported as assignments, and pages made with Canvas's newer block editor, are not handled yet. The bookmark says so if it meets one.
